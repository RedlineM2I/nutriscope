# Étude d'opportunités Nutriscope

*Proposé par la formatrice de ne faire que le chiffrage / coût et les six risques*

## Chiffrage / Coût

En se basant sur les données publiques de Yuka, on peut tenter d'estimer et chiffrer ainsi :

- Nombre d'instances par an : 2,7 milliards
- Nombre d'instances françaises par an : 670 millions (on va se baser sur cette valeur)
- Hypothèse : 5% de part de marché
- Nombre d'instances réévalué par la part de marché : 33,5 millions

- Gain par instance : 30s
- SMIC net horaire : 9,5€
- Gain monétaire par instance : 0.08€

- Hypothèse x succès = 15%

- Valeur annuelle : 33,5 millions x 0,08€ x 15% = 402 000 €

## Risques

- Le changement des codes-barres par des QR code [Probabilité : Forte / Impact : Faible]
- Rangement des produits par ordre de Nutriscore dans les grandes enseignes [Probabilité : Faible / Impact : Fort]
- Changement du calcul du Nutriscore [Probabilité : Forte / Impact : Faible]
- Évolution de la technologie et des usages (lunettes connectées) [Probabilité : Faible / Impact : Moyen]
- Évolution des technologies de développement et dépendances rompues [Probabilité : Forte / Impact : Fort]
- Nouveau concurrent ayant un impact sur le marché [Probabilité : Moyenne / Impact : Moyen]
